# 通用配图生成大师Skill

经过6轮深度优化打磨的**通用配图生成方法论**，适用于各类文章、公众号、头条号、小红书等平台的封面图和正文配图生成。

## 核心特色

- **8步SOP流程**：从选题分析到发布归档，完整的配图生成流程
- **8项质量评估标准**：信息密度、视觉层次、颜色语义、角色表现力、逻辑连接、系列一致性、图文对应、手机可读性
- **5种构图库**：对角线、三角形、环形、放射状、对称，轮换使用
- **颜色语义系统**：红=金句、橙=数据、蓝=判断，心理学运用
- **情感曲线设计**：6张图标准情感起伏（悬念→惊讶→佩服→怀疑→洞察→参与）
- **高级技巧**：多层隐喻系统、读者代入感设计、对比冲突视觉化、统一符号系统
- **Prompt模板**：封面图+正文图，开箱即用
- **常见问题解决方案**：7个常见问题的详细解决方案

## 最重要的优化原则

**做减法，不做加法！**
- 每次优化只保留最有价值的1-2个方向
- 避免同时优化多个方向导致元素过多
- 如果优化后变乱，立即回退到上一版

## 快速开始

1. 阅读 `SKILL.md` 了解完整方法论
2. 按照8步SOP生成配图
3. 使用8项标准评估质量
4. 优化迭代2-3轮（注意做减法）
5. 发布并归档
