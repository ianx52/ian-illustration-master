# 通用配图生成大师Skill v2.2

经过6轮深度优化打磨+实际使用验证的**通用配图生成方法论**，适用于各类文章、公众号、头条号、小红书等平台的封面图和正文配图生成。

## 核心特色

### v2.2新增功能（8个新模块）

1. **附录A：配图行业垂直适配** - 科技/金融/汽车/医疗/教育/房地产6大行业专属配色、构图、符号、模板
2. **附录B：品牌视觉识别系统VI** - 品牌色彩系统、字体系统、Logo规范、IP角色详细设定（外貌/性格/服装库/道具库/表情库/动作库）、视觉元素库
3. **附录C：配图心理学运用深度指南** - 颜色心理学/构图心理学/人物心理学/文字心理学/符号心理学/留白心理学，深度解析每个元素的心理影响
4. **附录D：快速生成模板库** - 10种封面图模板+10种正文图模板，直接填空就能用，效率提升50%
5. **附录E：配图生成的工作流自动化** - 批量生成/API调用/自动裁剪/自动压缩/自动上传，工具对比和代码示例
6. **附录F：配图的质量评分自动化工具** - AI自动评估/OCR文字识别/对比度检测/元素重叠检测/构图分析，自动化质量评分流程
7. **附录G：配图的成本和效率优化** - 时间成本分析/金钱成本分析/ROI分析/效率提升6大策略/成本控制5大策略
8. **附录H：配图法律风险深度指南** - AI版权归属/肖像权/商标权/著作权/虚假信息/敏感内容/4个侵权案例分析/完整版合规检查清单

### v2.1核心功能（5个高优先级优化）

1. 配图色彩具体色值规范（红#E53935、橙#FB8C00、蓝#1E88E5）
2. 配图文字字体和排版规范（6级字号，最小≥24px，行间距1.5倍）
3. 配图尺寸和比例规范（多平台自适应，基础1920x1080，安全区域1280x720）
4. Prompt模板增加负面提示词（避免真实人物肖像、品牌logo、渐变、阴影等）
5. 配图版权和合规指南（AI版权、肖像权、品牌logo、敏感内容、各平台审核规则）

### v2.0核心功能（8大模块）

1. 可量化质量检查清单（8项标准每项3-5个检查项）
2. 5种内容类型适配指南（时政/科技/汽车/人物/热点）
3. 配图数量和位置具体规则
4. 3步人工审核流程（快速/深度/系列检查）
5. 3轮优化策略和停止条件
6. 3个典型失败案例和避坑指南
7. 配图与标题呼应规则
8. Prompt质量检查提示词

### 原有基础功能

- **8步SOP流程**：选题分析→脚本设计→草图绘制→AI生成→质量评估→优化迭代→多平台适配→发布归档
- **8项质量评估标准**：信息密度、视觉层次、颜色语义、角色表现力、逻辑连接、系列一致性、图文对应、手机可读性
- **5种构图库**：对角线、三角形、环形、放射状、对称，轮换使用
- **颜色语义系统**：红=金句、橙=数据、蓝=判断，心理学运用
- **情感曲线设计**：6张图标准情感起伏（悬念→惊讶→佩服→怀疑→洞察→参与）
- **高级技巧**：多层隐喻系统、读者代入感设计、对比冲突视觉化、统一符号系统
- **Prompt模板**：封面图+正文图，含质量检查提示词+负面提示词
- **15个常见问题解决方案**
- **配图效果数据跟踪**（可选）

## 最重要的原则

**做减法，不做加法！**
- 每次优化只保留最有价值的1-2个方向
- 避免同时优化多个方向导致元素过多
- 如果优化后变乱了，立即回退到上一版
