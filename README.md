# 通用配图生成大师Skill v2.1

经过6轮深度优化打磨+实际使用验证的**通用配图生成方法论**，适用于各类文章、公众号、头条号、小红书等平台的封面图和正文配图生成。

## 核心特色

### v2.1新增功能（5个高优先级优化）

1. **配图色彩具体色值规范** - 红#E53935、橙#FB8C00、蓝#1E88E5，5种内容类型专属配色方案，确保颜色一致性
2. **配图文字字体和排版规范** - 6级字号规范（96px-24px）、行间距1.5倍、对齐方式、安全区域，确保排版专业性
3. **配图尺寸和比例规范（多平台自适应）** - 基础尺寸1920x1080，安全区域1280x720，覆盖头条/公众号/小红书/微博/B站/知乎6大平台，5种比例导出
4. **Prompt模板增加负面提示词** - 避免AI生成不需要的元素（真实人物肖像、品牌logo、渐变、阴影、3D效果等），提升首版生成质量
5. **配图版权和合规指南** - AI生成图片版权问题、人物肖像权、品牌logo、敏感内容、虚假信息、各平台审核规则、免责声明、合规检查清单

### v2.0核心功能（8大模块）

1. **可量化质量检查清单** - 8项标准每项增加3-5个具体检查项
2. **5种内容类型适配指南** - 时政/科技/汽车/人物/热点，每种类型有专属核心隐喻、配色、构图、角色、符号系统
3. **配图数量和位置具体规则** - 明确配图数量、位置（小标题前面）、顺序规则
4. **3步人工审核流程** - 快速检查（必须修复）+深度检查（建议修复）+系列检查（必须修复）
5. **3轮优化策略** - 第1轮修复必须问题+第2轮优化建议问题+第3轮微调一致性，明确停止条件
6. **3个典型失败案例** - 元素过多失败/ref失效失败/配图位置混乱失败，详细避坑指南
7. **配图与标题呼应规则** - 封面图与标题呼应+正文配图与小标题呼应+整体调性呼应
8. **Prompt质量检查提示词** - 在Prompt模板最后增加AI自我检查项

### 原有基础功能

- **8步SOP流程**：选题分析→脚本设计→草图绘制→AI生成→质量评估→优化迭代→多平台适配→发布归档
- **8项质量评估标准**：信息密度、视觉层次、颜色语义、角色表现力、逻辑连接、系列一致性、图文对应、手机可读性
- **5种构图库**：对角线、三角形、环形、放射状、对称，轮换使用
- **颜色语义系统**：红=金句、橙=数据、蓝=判断，心理学运用
- **情感曲线设计**：6张图标准情感起伏（悬念→惊讶→佩服→怀疑→洞察→参与）
- **高级技巧**：多层隐喻系统、读者代入感设计、对比冲突视觉化、统一符号系统
- **Prompt模板**：封面图+正文图，含质量检查提示词+负面提示词
- **15个常见问题解决方案**
- **配图效果数据跟踪**（可选）

## 最重要的原则

**做减法，不做加法！**
- 每次优化只保留最有价值的1-2个方向
- 避免同时优化多个方向导致元素过多
- 如果优化后变乱了，立即回退到上一版
